# 三分钟演示剧本

目标是在 3 分钟内讲清四件事：匿名集、能力隔离、两条真实业务链、主人对账与对照面板。录制前先执行一次 `run.sh`，确认页面已就绪，避免把首次编译和 setup 录进正式演示。

## 录制前

1. 终端执行 `bash scripts/demo/run.sh`，等页面显示 20 个模拟用户和 25 张票据。
2. 浏览器打开 `http://127.0.0.1:4179`，缩放设为 100%，隐藏书签栏和系统通知。
3. 确认采购、理财都处于“待执行”，不要提前点击。
4. 录屏窗口建议 1440 x 900，保留页面顶部状态和主要卡片。

## 备用 60 秒版本

如果现场时间被压缩：

- 0:00-0:10：标题、模拟数据、两条预算。
- 0:10-0:18：点击越权检查，说明能力由凭证和电路约束。
- 0:18-0:38：执行采购，展示 x402 交易与 Alice 解密结果。
- 0:38-0:55：理财存入并赎回，展示承诺票据和账本。
- 0:55-1:00：切换对照面板，说明 ERC-7710 的可关联性。

## 不要过度表述

- 不说“匿名”或“无法追踪”，说“不向商家和链上公开付款主体”。
- 不说“生产级可信设置”，说“本地单次 phase-2，仅演示”。
- 不说 100 spUSD 理财收益有代表性；重点是可执行承诺，不是收益率。
- 不说 ERC-7710 一定暴露全部字段；具体日志取决于 Smart Account 实现。
