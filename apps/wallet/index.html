给 AI Agent 的隐私预付卡

用 Face ID 给你的任何 Agent 发一张卡：有额度、有用途限制、随时冻结。 Agent 每一笔消费都瞒不了你，而商家和钱包商都不知道这张卡属于谁。

查看源码 产品方案

钱包 UI 正在开发中。这个页面先占住 shadowpass-wallet.vercel.app， 它同时是 passkey 的 RP ID 和零知识证明产物的托管地址。

商家看到的是资金池

链上只看到资金池里某个已授权的 Agent，看不到你的地址，消费无法被串联到个人。

钱包商只看到入金

授权关系与花费明细不经过钱包商，它只知道你往池子里放了多少。

只有你能对账

用你自己的查看钥解密每一笔消费，Agent 瞒不了你，也不需要信任任何第三方。

能力逐级收窄

零知识委托链让下级 Agent 的额度和有效期只能更小；被注入攻破的采购 Agent 碰不到理财资金。
